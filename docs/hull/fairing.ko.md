# Fairing

Fairing은 선체 표면에 직접 작은 국부적 수정을 가할 수 있게 해줍니다 — 정점을 미세 조정하거나, 패널을 분할하거나, 변형 격자(lattice)로 특정 영역의 형상을 다듬을 수 있으며, 곡률(fairness) 히트맵으로 결과를 시각적으로 확인할 수 있습니다.

![Fairness 히트맵이 활성화된 Fairing 탭](../assets/screenshots/hull-fairing.png)

Fairing 서브탭을 열면 자동으로 3D View의 **Surface** 레이어가 켜지고(그리고 촘촘한 **Mesh** 와이어프레임은 꺼집니다) — Fairing 편집은 음영 표면 위에서 직접 이루어지기 때문입니다.

## 정점과 면 편집하기

3D View에서 선체 표면의 **정점(vertex)**이나 **면(face)**을 클릭해 선택합니다.

- **정점 선택 시**: 현재 X/Y/Z 위치와 **dx/dy/dz (m)** 세 필드가 표시됩니다. 오프셋 값을 입력하고 **Apply**를 클릭하거나, 3D View에서 정점을 직접 클릭-드래그할 수 있습니다(드래그하는 동안 점선 가이드와 실시간 dX/dY/dZ 툴팁이 커서를 따라다닙니다). 중심선(Y ≈ 0)에 있는 정점은 **dy**가 0으로 고정되어 실수로 좌우 대칭이 깨지는 것을 방지하며, 해당될 때마다 이를 설명하는 안내 문구가 표시됩니다.
- **면 선택 시**: 강조 표시된 면 안쪽을 더블클릭하면 그 면이 **분할**됩니다(클릭한 지점에 정점이 추가되고 재삼각분할됩니다) — 이후 그 영역을 더 세밀하게 정점 편집할 수 있게 됩니다.

편집하면 하부 표면 메시가 다시 계산되고, 영향을 받은 station/waterline/buttock line과 정수력학, C<sub>P</sub> 곡선도 자동으로 다시 계산됩니다.

## Fairness 히트맵

Fairing 서브탭에 있을 때(그리고 Surface가 켜져 있을 때) 3D View의 **Surface** 레이어는 초록→주황→빨강 곡률 히트맵으로 바뀝니다. 초록은 국부 곡률이 낮음("fair"), 빨강은 곡률이 높음(꺾임이나 돌출부일 가능성)을 의미합니다.

3D View 아래에 범례가 표시됩니다:

| 요소 | 의미 |
|---|---|
| **Fairness** 라벨 | 범례가 곡률 척도임을 나타냅니다. |
| **Better** / **Worse** 캡션 | 초록(왼쪽) 끝 = 더 매끄러움/양호; 빨강(오른쪽) 끝 = 더 거칠음/불량. |
| 숫자 입력 두 개 | 색상 스케일이 늘어나는 최소/최대 곡률값입니다 — 최대값을 낮추면 미세한 곡률 변화가 더 잘 보이고, 높이면 매우 거친 메시에서 노이즈를 줄일 수 있습니다. |

범례(와 히트맵 자체)는 **Surface** 레이어가 켜져 있을 때만 표시됩니다.

## Undo / Redo

패널 하단의 **Undo**/**Redo** 버튼은 정점 이동, 면 분할, Variation/FFD 적용을 포함한 모든 선체 편집 이력을 앞뒤로 이동합니다.
